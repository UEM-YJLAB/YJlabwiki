## 本站收什么

- **世代编年史**：实验室按时间划分的各个阶段，人员、方向、成果与经验教训
- **组别**：常设小组的职责、人员、日常工作、工具资源与交接清单
- **帮助**：编辑方式与写作规范

## 本站不收什么

::: ambox 内容边界
以下内容**不要**写进维基。写之前先问自己：这段内容如果被全实验室、以及未来所有新人都看到，有问题吗？
:::

- **个人隐私**：手机号、身份证号、家庭住址、银行账号、体检结果
- **未公开的评审与举报**：审稿人身份、未定稿的评价、对他人的负面判断
- **有保密义务的材料**：合作方未公开的数据、企业横向项目的内部资料、专利未公开的技术细节
- **大文件**：数据集、原始实验记录、PPT、视频。这些放网盘，页面里贴链接
- **账号密码**：任何形式的凭据。需要共享的凭据放进密码管理器，维基里只写"存在哪里"

> 本仓库的所有分支和提交记录都公开。保密内容请放到组织批准的私有文档系统或独立私有仓库中。

## 隐私说明

- 本站没有独立用户注册系统，也没有第三方统计脚本
- 浏览器本地存储主题选择、当前标签页的答题放行状态、答题错误次数与锁定时间
- 当前托管平台为 GitHub Pages；访问日志按 [GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-privacy-statement)处理
- 页面正文及其 Git 提交记录保存在公开的组织仓库中，任何人均可读取
- 进门答题仅是浏览提示，页面正文、搜索索引与源码仍然公开，不提供保密访问控制
- 每次编辑都会在 Git 提交记录里留下你的账号名与时间

:::

| 角色 | 姓名 | 从何时起 | 负责什么 |
| --- | --- | --- | --- |
| 主维护者 | 待补充 | 待补充 | 仓库权限、域名与托管、结构规划 |
| 备份维护者 | 待补充 | 待补充 | 主维护者联系不上时接手 |

仓库归属 UEM-YJLAB 组织，成员使用各自的 GitHub 账号，通过组织团队取得编辑或维护权限。
组织管理员在交接时更新成员、团队与仓库角色；共享维护资料由组织批准的密码管理器保存。

## 技术说明

| 层 | 用了什么 |
| --- | --- |
| 内容 | Markdown 文件，存放在 `docs/` |
| 站点生成 | VitePress，皮肤是按 Wikipedia Vector (2010) 复刻的 |
| 版本管理 | Git，托管在 GitHub |
| 发布 | 提交到 `main` 后，由 GitHub Actions 构建并发布到 GitHub Pages |
| 搜索 | 构建时生成索引，浏览器端本地过滤，无后端 |
